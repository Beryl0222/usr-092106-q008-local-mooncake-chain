# 乡味月饼协作账

本仓库保存该服务的领域资料与最小事件约定，供业务团队在统一语义上继续建设。

## 已有内容

- `contracts/domain.schema.json`：领域事件的基础字段、聚合类型和事件名称。
- `data/sample.json`：可用于联调的中文样例记录。
- `src/validator.py`：事件信封与各事件必备字段的结构校验。
- `src/ledger.py`：追加式协作账，入账时执行检验、过敏原、产能与结算幂等等领域规则。
- `src/trace.py`：退货反查（订单→批次→班次→原料）与异常原料影响面，冻结范围精确到受影响的批次与订单。
- `src/public_view.py`：扫码公开视图，只含产地与制作信息，不带出村民收入。
- `src/planning.py`：缺料与交付风险投影，供工坊节前重排参考。
- `tests/`：验证样例、结构约定与领域规则保持一致。

## 领域边界

当前资料围绕批次谱系、配方过敏原和产能排程整理。事件一旦被接收，其标识、发生时间和版本不应被原地改写；业务更正应产生后继记录。涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段。

入账规则要点：原料须检验合格且未冻结才能投料；成品标签过敏原必须等于实际投料批次过敏原的并集（获准的地方配方可以不同，标签必须反映实际）；班次产量不超过师傅日产能；预售取消、临期转渠道和节前加单通过 `ORDER_REALLOCATED` 在产能与保质期内重排；线下称重与工时补录的结算按幂等键只付款一次。
