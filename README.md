# 乡味月饼协作账

屯昌多家小工坊中秋季产销协作的后端领域资料：只追加事件契约 + 纯标准库的
领域逻辑与校验，围绕**双向追溯、过敏原标签、扫码隐私、产能内重排、
线下单据一次付款**五件事给出可运行的语义。

## 解决什么

- **退货反查**：一张消费者退货单 → 成品批次 → 班次/师傅 → 配方版本 →
  全部原料批次与供应户。
- **异常正查**：一批异常原料 → 精确的受影响成品、预留订单与在途发货，
  冻结只覆盖真实下游，同品类其他批次不被牵连。
- **公开不带收入**：扫码只看到产地（到村）、工坊资质、制作班次、配方与
  过敏原；供应户姓名、单价、银行尾号在白名单投影之外。
- **地方配方各自获准**：少芝麻版等变体合法，但标签必须覆盖实际投料引入的
  全部过敏原，漏标不得放行。
- **产能内重排**：预售取消释放的库存优先给加单、临期批次按到期日转渠道、
  排不下的加单立即产生缺料旗标。
- **只付一次**：线下称重单、工时补录单靠幂等键与 `source_refs` 双保险，
  重复补录无法入账、已付来源无法再付。

## 目录

- `contracts/domain.schema.json`：26 类事件、10 类聚合的完整契约（含每类载荷约束）。
- `docs/domain.md`：领域边界、标识表与各规则说明。
- `src/`：`validator`（校验）、`ledger`（只追加账本）、`readmodel`（事件流快照）、
  `quality`（放行/过敏原）、`traceability`（双向追溯/精确冻结）、
  `privacy`（公开投影）、`planning`（重排）、`settlement`（一次付款）、
  `commands`（信封构造与落账）。
- `tests/fixtures.py`：两工坊 2026 中秋季完整场景；`data/sample_events.jsonl`
  是该场景的 45 条事件，可直接联调。

## 事件语义底线

事件一经接收，其标识、发生时间和版本不被原地改写；业务更正追加后继事件。
涉及个人与商业敏感信息（村民收入、银行信息）时，读取侧只暴露完成职责所
必需的字段——公开扫码视图是白名单投影，不是内部记录删字段。
